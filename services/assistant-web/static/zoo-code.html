Official setup docs ↗
  1. Install Zoo Code, then open its panel from the VS Code Activity Bar.
  2. Open Zoo Code settings and set API Provider to OpenAI Compatible.
  3. Paste the Base URL and a newly created credential into API Key.
  4. In the Model picker, explicitly select the model shown below. If it is not listed, search for the exact ID and choose Use custom; do not leave gpt-4o selected.
  5. Set Context Window Size and Max Output Tokens. Actively turn Image Support off because Zoo enables it by default; keep Prompt Caching and Enable Reasoning Effort off.
  6. Turn Enable streaming and Include max output tokens on.
